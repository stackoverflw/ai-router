# AI Router

A lightweight AI Router framework for hybrid local-cloud LLM deployment.

## Features

- Local LLM routing
- Cloud model fallback
- Token cost optimization
- Ollama integration

## Architecture

User
 ↓
AI Router
 ↓
Local Model / Cloud Model
